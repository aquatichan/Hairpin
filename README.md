# Hairpin

Hairpin lets you try any haircut on your own photo before you sit in the barber's chair: browse the hair library or upload a screenshot of a cut you've seen, preview it on yourself, decode what it's called, and turn the one you like into a Barber Brief you can show your barber. It is a Next.js web app (installable as a PWA) that uses Firebase for sign-in and the Publik API for all AI, with an optional OpenAI fallback. To run it, `npm install`, copy `.env.example` to `.env.local`, replace the `PLACEHOLDER_[...]` values you have, and `npm run dev`; anything left as a placeholder simply stays switched off. To fill the landing page, drop a darkened-friendly haircut clip at `public/hero/hero.mp4` (with an optional `public/hero/poster.jpg`) and import photos or clips into the library with `node scripts/import-photos.mjs <folder>`.
